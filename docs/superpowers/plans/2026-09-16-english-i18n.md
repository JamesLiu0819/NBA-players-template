# 英文版(多語言)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓網站同時支援繁體中文跟英文兩種介面語言,使用者可以在 topnav 自己切換,球員模板/訓練優先序的兩個階段都涵蓋。

**Architecture:** `data/` 拆成 `data/zh/`(既有中文檔案搬進來,檔名改成繁體中文)跟 `data/en/`(新增,檔名沿用現有英文命名)。後端 `load_data(pool, lang)`/`load_archetypes(lang)` 依 `lang` 讀對應資料夾,三支 API 都多接受一個選填的 `lang` 欄位。兩處寫死在 Python 裡的中文句型模板改成 lang-keyed 字典。前端新增 `UI_STRINGS` 字典跟 topnav 語言選項。`/src/engine` 完全不動。

**Tech Stack:** 既有 Flask + 標準函式庫 Python(後端)、vanilla JS 無框架(前端)——這次不新增任何依賴套件。

## Global Constraints

- 所有語言相關查找一律用「以 `lang` 字串為 key 的字典查找」,禁止 `if lang == "zh": ... else: ...` 或 `elif` 分支——加第三個語言以後只能是新增資料,不能是修改邏輯(設計文件 §3.6,使用者 2026-09-16 明確提出)。
- 合法語言清單只有一個來源:後端 `server/app.py` 的 `SUPPORTED_LANGUAGES`、前端 `index.html` 的 `SUPPORTED_LANGUAGES`,兩邊值必須一致(`("zh", "en")`),不要在別的檔案各自寫死。
- `data/en/` 的球員資料(`players.json`/`players_alltime.json`)是 `data/zh/` 對應檔案的**結構複製**,只翻譯 `notable_traits`,其餘欄位(`coordinates`、`body`、`mock_axis_answers`、`mock_skill_answers`、`signature_skill_id`、`learnability_flag`、`id`、`name`、`team`)逐位元相同——不透過 `mock_axis_answers`/`score_axis_coordinates` 重新建庫(設計文件 §3.2)。
- `reverse_scored: true` 的兩題(`axis_b3`、`axis_c1`)英文版錨點一樣要維持「1=字面頻率最少,5=字面頻率最多」的排列,跟中文版 2026-09-15 修正過的方向一致。
- `/src/engine/*.py` 這次不改任何一行程式碼(只有幾處註解語意上要更新檔名,不影響行為或測試)。
- 程式碼與 commit message 用英文;使用者看得到的文字(不管中文或英文版)照各自語言寫,不要英文版文案混進中文字或反過來。
- 每個 engine 之外會執行的新函數/新行為都要有單元測試,遵守既有 TDD 紀律(RED 先確認失敗原因,再寫最小實作)。
- 對應規格文件：`docs/superpowers/specs/2026-09-16-english-i18n-design.md`。

**內容要求(這是內容撰寫任務,不是預先把譯文寫進這份計畫——照下面的結構規則跟範例直接產生完整的 `data/en/questions.json`)：**

- [ ] **Step 1: 寫 `tests/engine/test_i18n_parity.py`,先只涵蓋 questions 這組(RED)**

```python
# 用途：驗證 data/zh/ 跟 data/en/ 的五組資料檔結構完全一致(id 集合、所有
# 非文字欄位),文字欄位兩邊都存在、非空、且不能相等(避免漏翻)。這是多語言
# 子專案最重要的安全網——任何一邊漏改都會讓這支測試失敗,不用等到使用者
# 真的切換語言才發現某個地方沒翻(見 docs/superpowers/specs/
# 2026-09-16-english-i18n-design.md §4)。
# 可手動調整的變數：無——這裡是通用比對邏輯,不含需要人工校準的參數。

import json
import unittest
from pathlib import Path

DATA_DIR = Path(__file__).resolve().parents[2] / "data"


def load_json(lang, filename):
    with open(DATA_DIR / lang / filename, encoding="utf-8") as f:
        return json.load(f)


class QuestionsParityTest(unittest.TestCase):
    def setUp(self):
        self.zh = load_json("zh", "題庫.json")
        self.en = load_json("en", "questions.json")

    def _by_id(self, questions):
        return {q["id"]: q for q in questions}

    def test_axis_positioning_ids_match(self):
        zh_ids = {q["id"] for q in self.zh["axis_positioning"]}
        en_ids = {q["id"] for q in self.en["axis_positioning"]}
        self.assertEqual(zh_ids, en_ids)

    def test_skill_behavior_ids_match(self):
        zh_ids = {q["id"] for q in self.zh["skill_behavior"]}
        en_ids = {q["id"] for q in self.en["skill_behavior"]}
        self.assertEqual(zh_ids, en_ids)

    def test_body_measurements_ids_match(self):
```

```python
    if len(ranked) < 2:
        return None
    higher, lower = ranked[0], ranked[1]
    if higher["P"] == lower["P"]:
        return TIE_SENTENCE_TEMPLATE[lang].format(
            higher=higher["name_zh"], lower=lower["name_zh"]
        )
    result = explain_dominant_factor(higher, lower)
    dominant = result["factor"]
    labels = FACTOR_LABELS[lang]
    others = [labels[f] for f in ("G", "E", "R", "C") if f != dominant]
    return DOMINANT_SENTENCE_TEMPLATE[lang].format(
        higher=higher["name_zh"],
        lower=lower["name_zh"],
        dominant_label=labels[dominant],
        ratio=result["ratio"],
        others=OTHERS_JOIN[lang].join(others),
```

```js
  const LANG_BUTTON_LABELS = { zh: "中", en: "EN" };

  function renderLangSwitch() {
    const container = document.getElementById("lang-switch");
    container.innerHTML = "";
    for (const lang of SUPPORTED_LANGUAGES) {
      const btn = document.createElement("button");
      btn.type = "button";
      btn.textContent = LANG_BUTTON_LABELS[lang] || lang;
      if (lang === state.lang) btn.classList.add("active");
      btn.addEventListener("click", () => setLang(lang));
      container.appendChild(btn);
    }
  }

  function applyUiStrings() {
    const strings = t();
    document.title = strings.pageTitle;
    document.querySelector(".masthead h1").textContent = strings.pageTitle;
    document.querySelector(".masthead .eyebrow").textContent = strings.eyebrow;
    document.querySelector(".masthead p").textContent = strings.subtitle;
    document.querySelector(".rules-box h2:nth-of-type(1)").textContent = strings.rulesTitle;
    document.querySelectorAll(".rules-box p")[0].textContent = strings.rulesLine1;
    document.querySelectorAll(".rules-box p")[1].textContent = strings.rulesLine2;
    document.querySelector(".rules-box h2:nth-of-type(2)").textContent = strings.warningTitle;
    document.querySelectorAll(".rules-box p")[2].textContent = strings.warningLine1;
    document.querySelectorAll(".rules-box p")[3].textContent = strings.warningLine2;
    document.querySelectorAll(".rules-box p")[4].textContent = strings.warningLine3;
    document.querySelector("#mode-current-btn .mode-title").textContent = strings.modeCurrentTitle;
    document.querySelector("#mode-alltime-btn .mode-title").textContent = strings.modeAlltimeTitle;
  }

  function setLang(lang) {
    if (lang === state.lang) return;
    state.lang = lang;
    localStorage.setItem("lang", lang);
    renderLangSwitch();
    applyUiStrings();
    // 作答中的那一題也要重繪成新語言,不用整頁重整
    if (document.getElementById("stage1-form").style.display !== "none") {
      renderStage1Wizard();
    }
    if (document.getElementById("stage2-block").style.display !== "none"
        && document.getElementById("stage2-block").style.display !== undefined) {
      renderStage2Wizard();
    }
  }
```
